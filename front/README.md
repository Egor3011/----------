# Воробьев Никита — Vue сайт

Адаптивная верстка по desktop/mobile макетам.

## Запуск

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
```

## Запуск на Ubuntu через Docker

Установите Docker Engine и плагин Docker Compose. Из корня репозитория выполните:

```bash
docker compose up -d --build
```

Сайт будет доступен по адресу `http://IP_СЕРВЕРА/`. Если на сервере включён UFW, откройте порт: `sudo ufw allow 80/tcp`.

Для другого HTTP-порта задайте `HTTP_PORT`, например:

```bash
HTTP_PORT=8080 docker compose up -d --build
```

После изменения фронтенда повторите `docker compose up -d --build`. Остановить сайт можно командой `docker compose down`.

## Реализовано

- Vue 3 + Vite.
- Адаптивные desktop/mobile версии.
- Блоки «Обо мне», «Тарифы сеансов», FAQ и контакты.
- 10 вопросов и ответов в FAQ.
- Листание тарифов: 1, 5, 10 и 20 встреч.
- Первая встреча — 1.000 ₽ (скидка 50% от базовых 2.000 ₽).
- 5 встреч — 5.000 ₽, 50% скидка.
- 10 встреч — 7.500 ₽, 62,5% скидка.
- 20 встреч — 10.000 ₽, 75% скидка.
- Кнопки вперед/назад и точки навигации для тарифов.
- Анимации появления и hover-эффекты.
